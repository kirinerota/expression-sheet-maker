差分平铺工具（本地版）

使用方式：
1. 双击“启动本地版.bat”。
2. 点击左侧“导入立绘”，一次选择全身立绘和全部差分。
3. 在“全身立绘”下拉菜单中选择作为左侧全身图的图片。
4. 在画布中点击姓名或全身立绘，可拖动；拖动四角控制点可缩放。
5. 在“头像网格”中设置列数和间距；在“立绘差分”中调整豆腐块内的差分位置、豆腐块尺寸和整组位置。
6. 右侧拖动缩略图可调整差分顺序；输入框可直接选择文字修改名称；单击画布上的差分名称也可修改。
7. 点击“导出 PNG”。

图片只在浏览器内处理，不会上传。

导出缩放使用项目内置的 pica.min.js 进行本地高质量处理，不依赖网络。
