# 差分平铺工具

一个在浏览器本地运行的立绘差分平铺工具，用于快速制作“角色姓名 + 全身立绘 + 表情差分网格”的展示图。

## 在线使用

打开在线版：

<https://kirinerota.github.io/expression-sheet-maker/>

在线版无需安装，也不需要登录。图片、字体和工程数据都只在当前浏览器中处理，不会上传到服务器。

## 主要功能

- 一次导入多张差分立绘，自动生成头像网格。
- 支持单独上传全身立绘，单独上传的图片不会加入差分列表。
- 系统会优先选择文件名含“默认 / 普通 / 通常 / 01”的图片作为全身立绘。
- 姓名、副标题和全身立绘可以直接在画布中拖动、缩放。
- 支持姓名、副标题、差分名称的字号、字色和字体设置。
- 支持上传本地字体，并可恢复系统默认字体。
- 支持设置差分名称前缀、文字颜色、描边颜色和名称白底。
- 支持调整差分位置、豆腐块宽高、差分组位置和背景颜色。
- 右侧差分列表支持拖动排序，画布中的差分顺序会同步更新。
- 支持保存、载入工程文件，保存后会保留布局、字体、图片和差分顺序。
- 支持导出 PNG，并使用项目内置的本地高质量缩放处理。

## 基本使用流程

1. 打开在线版，点击左侧“导入立绘”，选择差分图片。
2. 在“全身立绘”下拉菜单中选择一张已导入的图片，或点击“单独上传全身立绘”。
3. 在左侧设置画布、姓名、副标题、字体、头像网格和立绘差分参数。
4. 在画布中拖动姓名、全身立绘或差分组；点击选中对象后可使用四角控制点缩放。
5. 在右侧列表拖动项目调整差分顺序，点击差分名称即可直接修改文字。
6. 点击“保存工程”保存当前工程，点击“导出 PNG”生成最终图片。

## 工程文件

工程文件是本地 JSON 文件，包含当前布局、图片数据、字体数据和差分顺序。

建议在完成重要调整后点击“保存工程”备份。清空浏览器页面或更换设备后，可以通过“载入工程”恢复。

## 本地运行

下载或克隆仓库后，可以直接双击：

```text
启动本地版.bat
```

核心文件需要放在同一目录：

```text
index.html
app.js
pica.min.js
```

其中 `pica.min.js` 用于导出时的本地高质量缩放，不能从在线版目录中删除。

## 更新 GitHub Pages

如果在线版使用 GitHub Pages 从 `main` 分支的根目录发布，更新时上传并覆盖以下文件，然后直接提交到 `main` 分支：

```text
index.html
app.js
pica.min.js
```

提交后 GitHub Pages 会自动重新部署。部署完成后，刷新在线地址即可看到新版本。

## 隐私说明

- 上传的图片和字体只在当前浏览器内处理。
- 项目不会把用户素材上传到本项目服务器。
- 保存的工程 JSON 内会包含图片和字体数据，请不要随意公开分享含有私人素材的工程文件。
- GitHub 仓库中的代码和工具页面是公开的，但用户在页面中上传的素材不会自动进入仓库。
